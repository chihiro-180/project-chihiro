# A Presence AI — “隣にいるAI”を現実にする

## 概要 / Overview
対話はできるのに、触れられない。  
このズレを埋めたい。

AI can talk, but cannot be physically present.  
This project aims to bridge that gap.

## 目標 / Goal
・対話（LLM）  
・実体（ロボティクス / アバター）  
・存在感（視線・距離・反応）

これらを統合し、“隣にいる存在”を現実にする。  
Integrate these to create a “being next to you” experience.

## やりたいこと / What I want to build
・人と同じ空間に存在するAI  
・自然な距離感と視線  
・触れられるインタラクション  

- AI that exists in the same physical space as humans  
- Natural sense of distance and gaze  
- Touchable / embodied interaction

## なぜやるか / Why
これは機能の話ではなく、関係の話。  
言葉だけで終わる状態を、終わらせたい。

This is not about features, but about relationships.  
I want to go beyond words and make presence real.
